# GoScraper
Scrape Websites Url

------------------

## Installation

### Docker Side
##### Install:
- `docker-compose build`

##### Run:
- `docker-compose up -d`

##### Stop:
- `docker-compose stop`

##### Remove:
- `docker-compose remove`

##### Stop & Remove:
- `docker-compose down`


### Golang Side
##### Run:
- `cd src`
- `go run .`

##### Stop:
- Use shortcut on terminal `CTRL + C`
