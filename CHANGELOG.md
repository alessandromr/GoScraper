# Golang Scraper by Alessandro Marino

## 0.1.0 alpha
First release.

#### Added Functions

- Scan Page for URL
- Check if URL is valid
- Divide URL by internal and external starting from checked url
- Save cleaned url on Mysql Database
- Redis Key:Value storage for checked history
- IronMQ queue for next url to be checked
- Docker-Compose for Mysql/Redis/IronMQ+IronMQAuth
- (Docker-Compose) PhpMyadmin for Mysql server
